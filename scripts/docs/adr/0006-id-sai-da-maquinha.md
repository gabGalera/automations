# O id sai da Maquinha quando a venda chega

Um Id Transação Adquirente que está na Maquinha sai quando chega uma transação ou um recebível desse id. As tuplas dele entram no consolidado: positiva na linha sem confirmação de Data Repasse mais cedo, negativa como estorno sem parcela. O valor e a data saem do `Recebimentos_MP.xlsx`. Fica de fora deixar o id na Maquinha para sempre.
