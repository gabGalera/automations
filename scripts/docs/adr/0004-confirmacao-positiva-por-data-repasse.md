# Confirmação positiva ocupa a linha sem confirmação de Data Repasse mais cedo

Uma tupla nova de confirmação MP positiva entra na primeira linha daquele Id Transação Adquirente que ainda não tem confirmação, na ordem de Data Repasse. A mesma tupla não entra de novo; outra data é outra tupla. Fica de fora numerar parcela 1, 2, 3 pela ordem da Data Recibo MP: o arquivo não traz número de parcela, e um positivo no dia de um estorno (sobra) não é a parcela seguinte.
