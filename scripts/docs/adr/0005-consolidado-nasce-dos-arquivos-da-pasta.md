# O consolidado nasce do merge dos arquivos que já estão na pasta

A lista não é copiada do `output.xlsx` atual. Transações, recebíveis e confirmações MP já presentes na pasta entram no merge, inclusive tuplas que antes estavam só marcadas como vistas. A ordem é: CSV de transação do mais antigo para o mais novo, depois CSV de recebível na mesma ordem, por último o `Recebimentos_MP.xlsx` inteiro. Assim a parcela já está na lista quando a confirmação positiva procura a Data Repasse. A mesma tupla não entra de novo depois disso. Tupla cujo id não está em nenhuma transação nem recebível da pasta não entra no consolidado: o id vai para a Maquinha. A releitura da pasta acontece uma vez, para criar o consolidado. Depois só entram chegadas novas. Reiniciar o processo não refaz a lista. Fica de fora copiar a planilha de hoje e entrar confirmação de id que ainda não está nos CSV.
