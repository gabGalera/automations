# Triage Labels

The skills speak in terms of five canonical triage roles, plus `completed` once the work is finished. This file maps those roles to the actual label strings used in this repo's issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | Maintainer needs to evaluate this issue  |
| `needs-info`               | `needs-info`         | Waiting on reporter for more information |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `ready-for-human`    | Requires human implementation            |
| `wontfix`                  | `wontfix`            | Will not be actioned                     |
| `completed`                | `completed`          | The ticket's work is done                |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table. `completed` is the label `/implement` writes when the ticket's work is finished.

Edit the right-hand column to match whatever vocabulary you actually use.
